# SplitQuote — PWA-калькулятор заявок для мастеров по кондиционерам

Повторение схемы из видео «24 часа на веб-кодинг» (youtu.be/EldVrt2-1Pk),
адаптированное под Анапу / Краснодарский край.

**Продукт:** сайт-PWA, который мастер ставит ссылкой в VK/Avito/Telegram.
Клиент сам считает примерную цену, прикладывает фото и адрес — заявка падает
мастеру в дашборд и в Telegram.

**Цена для клиента-мастера:** 4 900 ₽ за настроенную версию + хостинг.

## Статус

Этап 0 — подготовка. Код ещё не начат, ждём пример видео от заказчика.

## Структура

```
docs/01-scheme.md    — разбор схемы из видео: что повторяем, что меняем
docs/02-product.md   — продукт, экраны, формула калькулятора, тарифы
docs/03-plan.md      — этапы, сложность, риски, чек-лист
```

## Стек (предварительно)

- Frontend: React + Vite + TypeScript, PWA (manifest + service worker)
- Backend: Supabase (free tier) — БД, auth мастера, storage для фото
- Уведомления: Telegram-бот (заявка приходит мастеру в чат)
- Деплой: Vercel / Netlify (free) на демо, VPS для клиентских версий
- Разработка: OpenCode CLI (`opencode.cmd run -m plusvibe/deepseek-v4.1-flash-1017`)
