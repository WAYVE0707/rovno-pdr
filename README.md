# СметаОнлайн — PWA-калькулятор и приём заявок для бригад по заборам и навесам

Повторение схемы из видео «24 часа на веб-кодинг» (youtu.be/EldVrt2-1Pk).
Ниша выбрана по всей России — продаём удалённо, город не важен.

**Продукт:** сайт-PWA, который мастер ставит ссылкой в Avito/VK/Telegram.
Клиент сам считает вилку цены забора, прикладывает фото участка и адрес —
заявка падает в дашборд мастера и в Telegram.

**Цена для клиента:** 4 900 ₽ за настроенную версию + хостинг на нём.

## Статус

Этап 0 — подготовка. Ждём видео-референс от заказчика, код ещё не начат.

## Стек (предварительно)

- Frontend: React + Vite + TypeScript, PWA (manifest + service worker)
- Backend: Supabase (free) — БД, вход мастера, storage для фото
- Уведомления: Telegram-бот (заявка приходит мастеру в чат)
- Деплой: Vercel/Netlify (free) на демо, VPS для клиентских версий
- Разработка: OpenCode CLI (`opencode.cmd run -m plusvibe/deepseek-v4.1-flash-1017`)
