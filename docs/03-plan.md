# 03. План работ

## Блоки и сложность

| Блок | Что внутри | Сложность | Оценка |
|---|---|---|---|
| Каркас PWA | Next.js/React или чистый Vite + manifest + service worker | низкая | 1 ч |
| Калькулятор | 4 шага, валидация, расчёт вилки по пресету | средняя | 2–3 ч |
| Загрузка фото | сжатие на клиенте, до 5 файлов, превью | средняя | 1–2 ч |
| Сохранение заявки | БД (SQLite/Postgres) + админка списка | средняя | 2 ч |
| Telegram-уведомление | бот, отправка фото + кнопки статуса | низкая | 1 ч |
| Админка настроек | прайс, коэффициенты, тексты, chat_id | средняя | 2 ч |
| Дизайн | мобильный-first, блок «до/после», ликбез | средняя | 2–3 ч |
| Деплой | домен, HTTPS, деплой на Pages/VPS | низкая | 1 ч |
| **Итого MVP** | | | **12–15 ч** |

3D-модели из видео не делаем — минус 4–6 часов.

## Порядок
1. Пресет PDR (`presets/pdr.json`) → каркас → калькулятор с расчётом (без фото).
2. Фото + сохранение заявки + админка.
3. Telegram-бот и уведомления.
4. Дизайн и тексты, ликбез про PDR.
5. Демо-версия с тестовым прайсом для продаж.
6. Деплой демо на бесплатный поддомен.

## Продажи
1. Собрать базу 150–200 мастеров (Avito, VK, 2ГИС) — город, ссылка на профиль, телефон/TG, есть ли сайт.
2. Отсеять тех, у кого уже есть сайт с калькулятором.
3. Второй TG-аккаунт: прогрев 2–3 дня, лимит 10–20 новых касаний в день.
4. Скрипты из `docs/04-outreach.md`, персонализация под каждое объявление.
5. Оплата по НПД с чеком (`docs/05-payments.md`).
6. Первые 3 продажи — вручную, с созвоном и настройкой под клиента.

## Метрики первого месяца
- 300 касаний → 25–35 ответов → 4–6 демо → 2–3 продажи.
- Если после 100 касаний меньше 5 ответов — менять не продукт, а первые две строки сообщения.

## Риски
| Риск | Что делаем |
|---|---|
| Бан второго TG-аккаунта | Лимит 10–20 касаний/день, без ссылок в первом сообщении, разные тексты |
| Мастер говорит «дорого» | Показываем, что это 1–2 вмятины, и что клиент уходит к тому, кто назвал цену |
| Спрос сезонный (град) | Продаём круглый год: парковочные вмятины идут всегда |
| Клиент не понял, что такое PDR | Ликбез на главной + «до/после» |
| Оценка по фото неточная | Только вилка + дисклеймер «точная цена после осмотра» |
| Возвраты и споры | Оферта на 1 страницу, акт, правка бесплатно 14 дней |
