# 03. План, сложность, риски

## Насколько это сложно

| Блок | Сложность | Время (агент) | Комментарий |
|---|---|---|---|
| Лендинг + калькулятор | низкая | 2–3 ч | Форма с формулой и вилкой цены |
| Заявка → база (Supabase) | низкая | 1–2 ч | Готовый BaaS, свой бэкенд не нужен |
| Дашборд мастера | средняя | 2–3 ч | Список, статусы, карточка, прайс |
| Telegram-бот уведомлений | низкая | 1 ч | Bot API + webhook |
| PWA (manifest, SW, иконки) | низкая | 1 ч | Шаблонно, но много мелочей |
| Загрузка фото | средняя | 1–2 ч | Supabase Storage + сжатие на клиенте |
| 3D-модели (как в видео) | высокая | 4–6 ч | Не делаем на MVP |
| Деплой + домен | низкая | 0,5 ч | Vercel в один клик |
| **Итого MVP** | **средняя** | **8–12 ч** | 1–2 рабочих дня |

## Продажи — сложнее кода

| Блок | Сложность | Комментарий |
|---|---|---|
| Сбор базы | средняя | Avito, VK, 2ГИС, Профи.ру — 100–200 контактов |
| Проверка «кому подходит» | средняя | Отсеять тех, у кого уже есть онлайн-заявка |
| Персонализация | средняя | Найти конкретную ошибку в профиле → написать про неё |
| Переписка и демо | средняя | 5–15 сообщений на продажу |
| Оплата и передача доступов | низкая | Самозанятость + чек или платёжная ссылка |

Ориентир: **100 контактов → 8–12 ответов → 2–3 продажи.**
В видео 9 продаж из ~100 — верхняя граница, а не норма.

## Риски

1. **115-ФЗ при приёме денег на карту физлица.** В видео карту заблокировали.
   Решение: самозанятость + чек или платёжная ссылка (ЮKassa/Prodamus).
2. **Спам-блоки в VK/Telegram.** Лимиты 20–30 сообщений в день с аккаунта,
   персонализация, никакой массовой рассылки одним текстом.
3. **«У меня уже есть калькулятор на сайте».** Продаём не калькулятор, а поток
   заявок с фото и Telegram-уведомлением; демо показываем с его же прайсом.
4. **Сезонность.** Пик апрель–октябрь. Вне сезона — те же бригады собирают
   заявки на весну, плюс соседняя ниша «навесы».
5. **Один клиент = одна версия.** Нужен шаблон настройки (пресеты), иначе
   масштабирование съест всё время.
