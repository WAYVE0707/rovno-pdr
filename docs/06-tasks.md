## Задача 1. Оферта и акт (тексты)
**Файлы:** `docs/legal/oferta.md`, `docs/legal/akt.md`
**Сделать:** оферта на 1 страницу (предмет — услуги по разработке и настройке сайта, цена 4 900 ₽, срок 2 рабочих дня, что входит/не входит, правки 14 дней, возврат), акт на 1 страницу.
**Приёмка:** нет юридических терминов без пояснений, суммы и сроки совпадают с `docs/02-product.md`, формулировка «услуги», не «программа».

## Задача 2. Telegram-бот: команды мастера
**Файлы:** `server/bot.mjs`, правки `server/index.mjs`
**Сделать:** long polling (без webhook), команды `/start`, `/leads` (5 последних), `/today` (сумма за сегодня), `/settings` (показать текущий прайс). Уведомление о заявке уже есть — не ломать.
**Приёмка:** `node server/index.mjs` стартует без ошибок, команды отвечают при заданном `TELEGRAM_BOT_TOKEN`, без токена бот просто не запускается и пишет в лог.

## Задача 3. Сборка базы мастеров
**Файлы:** `scripts/collect_leads.py`, `data/prospects.csv`
**Сделать:** парсер выдачи по городам (Avito/2ГИС — только публичные страницы, с паузами), поля: город, имя, ссылка, телефон/telegram, есть ли сайт, дата.
**Приёмка:** CSV открывается в Excel, 50+ строк на 3 города, в логе нет ошибок 429/403.

## Задача 4. Пресеты для второй ниши
**Файлы:** `presets/<niche>.json`, `presets/calc_<niche>.py`
**Сделать:** пресет для «вывоз и демонтаж хлама» по той же схеме: поля, ставки, стоп-правила, тексты.
**Приёмка:** тесты расчёта проходят, UI подхватывает пресет сменой одного импорта.

## Задача 5. Деплой
**Файлы:** `docs/07-deploy.md`, `Dockerfile` (опционально)
**Сделать:** инструкция: VPS + домен + HTTPS (Caddy), systemd-юнит, переменные окружения, бэкап `data/`.
**Приёмка:** по инструкции с нуля поднимается рабочий сайт, `/api/health` отвечает.

## Правила для OpenCode
- Не менять `presets/pdr.json` без обновления `presets/calc.py`.
- После каждой задачи: `npm run build` и `python presets/calc.py` должны быть зелёными.
- Не трогать `.env`, ключи и `data/` (там реальные заявки).
- Коммит после каждой задачи, сообщение по шаблону `feat(<область>): ...`.
