# 10. Тест метода: работает или нет

Цель — за один вечер понять, покупают ли. Не «доработать сайт», а **получить первый ответ
от живого мастера**. Всё, что для этого нужно, уже готово.

## Критерий результата

- 20 сообщений → **1–2 ответа** = метод рабочий, продолжать.
- 20 сообщений → 0 ответов, но 5+ прочитали = менять текст первого сообщения.
- 20 сообщений → 0 прочитанных = не тот канал или не та база.

20 сообщений в день — норма. Больше с одного аккаунта не надо: Telegram начнёт резать.

## Шаг 1. База: 20 мастеров (40 минут с телефона)

2ГИС и Яндекс.Карты с сервера отдают капчу — собирай **с телефона**, вручную:

1. 2ГИС → город → поиск: «удаление вмятин», «PDR», «полировка вмятин», «ремонт вмятин».
2. Открываешь карточку → телефон, WhatsApp, Telegram, сайт, фото работ.
3. Пишешь в `data/prospects.csv`: название, город, телефон, канал, ссылка.

Города по приоритету: Ростов-на-Дону, Краснодар, Ставрополь, Воронеж, Армавир, Новороссийск,
Волгоград, Астрахань. Крупные города — больше мастеров, но и больше конкурентов; средние
(100–500 тыс.) отвечают чаще.

Ещё источники: Авито («услуги → авто → ремонт вмятин»), поиск Telegram «вмятины», «PDR»
по каналам, VK-группы автолюбителей города.

## Шаг 2. Демо-ссылка на каждого (2 минуты)

`/admin` → «Настройки» → блок **«Ссылка для переписки»**: вписал название, город, телефон,
имя — скопировал ссылку. Ссылку сохраняешь в таблицу рядом с контактом.

## Шаг 3. Первое сообщение — БЕЗ ссылки

Ссылку в первом сообщении не даём: выглядит как реклама, сразу закрывают. Первое сообщение —
вопрос по делу.

**Вариант А (вопрос):**
> Здравствуйте! Вы вмятины без покраски делаете? Хочу уточнить по одной детали — есть вмятина
> на двери, не понимаю, реально ли без покраски.

**Вариант Б (по его профилю):**
> Здравствуйте! Увидел ваши работы по PDR — на фото дверь после града. Подскажите, вы по городу
> выезжаете или только в боксе принимаете?

**Вариант В (сразу по делу, если он в переписке активен):**
> Здравствуйте! Я делаю сайты для PDR-мастеров — с калькулятором по фото, чтобы клиент сразу
> видел вилку и не звонил просто так. Вам актуально или уже есть сайт?

Цель первого сообщения — **получить ответ**, а не продать. Продажа идёт во втором-третьем.

## Шаг 4. Ответил — показываем демо

> «Смотрите, вот пример: <ссылка>. Это под вашим названием и городом — калькулятор считает
> вилку по фото, заявка падает в Telegram. Настраиваю под вас за день.»

Дальше по `docs/PLAYBOOK.md` §3–4 (возражения) и §5 (оплата).

## Шаг 5. Фиксация

`data/prospects.csv` — после каждого диалога:

| Поле | Что писать |
|---|---|
| client | название мастерской |
| city | город |
| contact | телефон / @username |
| channel | tg / wa / звонок |
| sent_at | дата первого сообщения |
| status | отправлено / прочитано / ответил / отказ / думает / продано |
| note | что сказал, что мешает |

## Что делать, если 20 сообщений не дали ответа

1. Проверить базу: если у мастеров в профиле «только по записи, бокс» — им сайт не нужен,
   им нужен поток. Ищи выездных.
2. Сменить город на средний (100–500 тыс.): в них меньше демпинга и меньше «своих» сайтов.
3. Сменить первое сообщение: не про сайт, а про заявки («сколько заявок в неделю приходит?»).
4. Проверить, не в спаме ли аккаунт: отправить 5 сообщений знакомым, посмотреть, доходит ли.
